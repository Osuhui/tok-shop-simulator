1.2 架构设计

分层架构：严格分离游戏逻辑与渲染层。

🏗️ 三层架构

层职责依赖方向
渲染层 React组件 + R3F 3D场景。订阅Store，渲染UI和3D。 → 依赖Store，不直接调用Game System
状态层 Zustand Store。持有所有游戏状态，暴露actions。中间层。 → 调用Game System获取结果，更新状态
逻辑层 纯函数Game System。所有计算公式、规则、判定。无副作用。 → 不依赖任何框架，可独立单测

🔄 数据流

用户点击 "发货"
  → React Component 调用 store.action.shipOrder(orderId)
    → Store Action 调用 LogisticsSystem.shipOrder(state, orderId)
      → 纯函数返回新的 Order 状态 + 扣款金额
    → Store 用 immer 更新 orderStore
      → React UI 自动重渲染（订单状态变化）
      → R3F 场景自动更新（打包台上包裹消失）

3 游戏系统模块规格

3.1 时间系统 (GameLoop)

⏱️ 核心机制

  • 游戏时间独立：与现实时间无关，有自己的时间流速
  • 默认速度：1游戏日 = 30现实秒（可在1x/2x/4x间切换，支持暂停）
  • 实现方式：requestAnimationFrame 循环，累积delta时间，到达阈值推进1天
  • 每日结算触发：
    • 自然流量生成新订单
    • 订单超时检查（pending超过deadline → 扣分）
    • 在途库存到货
    • 已签收订单回款
    • 海外仓仓储费扣除
    • 随机事件判定
// src/game/engine/GameLoop.ts
export class GameLoop {
  private elapsed: number = 0;
  private dayDuration: number;  // 毫秒/游戏日

  constructor(speed: GameSpeed = '1x') {
    this.dayDuration = this.getDayDuration(speed);
  }

  private getDayDuration(speed: GameSpeed): number {
    switch (speed) {
      case 'pause': return Infinity;
      case '1x': return 30_000;   // 30秒/日
      case '2x': return 15_000;   // 15秒/日
      case '4x': return 7_500;    // 7.5秒/日
    }
  }

  /** 每帧调用，返回本帧是否触发了新的一天 */
  tick(deltaMs: number): boolean {
    if (this.dayDuration === Infinity) return false;
    this.elapsed += deltaMs;
    if (this.elapsed >= this.dayDuration) {
      this.elapsed -= this.dayDuration;
      return true; // 触发日结算
    }
    return false;
  }

  setSpeed(speed: GameSpeed): void {
    this.dayDuration = this.getDayDuration(speed);
    this.elapsed = 0;
  }
}

3.2 供应链选品系统 (SourcingSystem)

📦 核心规则

  • 货盘刷新：每7个游戏日刷新一次供应链市场，展示8-12个可选商品
  • 区域过滤：只显示当前区域可用 + 已解锁区域可用商品
  • 采购操作：玩家输入数量 → 系统扣款 → 商品进入"在途库存" → N天后到货
  • 风险商品：山寨品采购价低60%但上架后触发风控概率+40%
  • 批量折扣：采购≥100件 → 9折；≥500件 → 8折
// src/game/systems/SourcingSystem.ts
export const SourcingSystem = {
  /** 获取当前可用货盘 */
  getAvailableProducts(allProducts: Product[], region: RegionId, day: number): Product[] {
    return allProducts.filter(p => p.regionAvailability.includes(region));
  },

  /** 计算采购成本 */
  calculatePurchaseCost(product: Product, quantity: number): number {
    let unitCost = product.cost;
    if (quantity >= 500) unitCost *= 0.8;
    else if (quantity >= 100) unitCost *= 0.9;
    return Math.round(unitCost * quantity * 100) / 100;
  },

  /** 计算到货时间 (天) */
  getArrivalTime(region: RegionId): number {
    return region === 'SEA' ? 2 : region === 'UK' ? 5 : 7;
  },
};

3.3 上架与合规检测系统 (ListingSystem)

🛡️ 违规词检测

  • 检测时机：玩家点击"上架"时实时检测标题文本
  • 品牌词库：Nike, Adidas, Gucci, LV, Dyson, Apple, iPhone, Stanley, etc.
  • 绝对化用语：最好、第一、100%、永久、根治、特效、一秒见效
  • 医疗功效词：防癌、治病、消炎、抗菌、美白祛斑（无认证时）
  • 处罚等级：
    • 轻（含1个违规词）：警告 + 需修改后重新上架
    • 中（含2-3个违规词或品牌名）：扣0.3健康分 + $200罚款
    • 重（山寨品+品牌名组合）：扣1.0健康分 + $500罚款 + 商品强制下架
// src/game/systems/ListingSystem.ts
interface ComplianceResult {
  passed: boolean;
  violations: string[];
  penaltyLevel: 'none' | 'light' | 'medium' | 'heavy';
  penaltyGold: number;
  penaltyHealthScore: number;
}

export const ListingSystem = {
  /** 合规检测 */
  checkCompliance(title: string, product: Product, region: RegionId): ComplianceResult {
    const violations: string[] = [];
    // 品牌词检测
    const brandWords = BRAND_BLACKLIST.filter(w =>
      title.toLowerCase().includes(w.toLowerCase()));
    violations.push(...brandWords.map(w => `品牌词 "${w}"`));

    // 绝对化用语检测
    const absoluteWords = ABSOLUTE_BLACKLIST.filter(w => title.includes(w));
    violations.push(...absoluteWords.map(w => `绝对化用语 "${w}"`));

    // 医疗词检测（仅当产品无相关认证时）
    if (!product.certifications.includes('FDA')) {
      const medicalWords = MEDICAL_BLACKLIST.filter(w => title.includes(w));
      violations.push(...medicalWords.map(w => `医疗功效词 "${w}"`));
    }

    // 判定处罚等级
    const hasBrandViolation = brandWords.length > 0;
    const isCounterfeit = product.riskLevel === 'counterfeit';

    if (violations.length === 0) return { passed: true, violations: [], penaltyLevel: 'none', penaltyGold: 0, penaltyHealthScore: 0 };
    if (isCounterfeit && hasBrandViolation) return { passed: false, violations, penaltyLevel: 'heavy', penaltyGold: 500, penaltyHealthScore: -1.0 };
    if (violations.length >= 2) return { passed: false, violations, penaltyLevel: 'medium', penaltyGold: 200, penaltyHealthScore: -0.3 };
    return { passed: false, violations, penaltyLevel: 'light', penaltyGold: 0, penaltyHealthScore: 0 };
  },

  /** 计算建议零售价 */
  calculateSellPrice(product: Product, region: RegionId, healthScore: number): number {
    const range = REGION_CONFIG[region].customerPriceRange;
    let price = Math.max(product.basePrice, range[0]);
    price = Math.min(price, range[1]);
    // 健康分高的店铺可以有10%溢价
    if (healthScore >= 4.5) price *= 1.1;
    return Math.round(price * 100) / 100;
  },
};

3.4 达人建联系统 (AffiliateSystem)

🤝 核心公式与流程

  1. 玩家在"Talent Hub"浏览达人列表（按区域/粉丝数/类目筛选）
  2. 选择达人 → 选择要推广的商品 → 出价佣金比例
  3. 系统计算成功率（见下方公式）
  4. 成功 → 即时生成大量订单（基于达人粉丝数×转化率）
  5. 失败 → 达人进入冷却，N天内不可再次邀约
达人合作成功率公式：

Psuccess = BaseWill × (1 + (Vplayer - Vexpected) / 20) × MatchScore × (1 - Frisk)

BaseWill达人基础合作意愿 (0.1-1.0)
Vplayer玩家出价佣金比例 (如0.25 = 25%)
Vexpected达人期望佣金比例 (如0.15 = 15%)
MatchScore商品与达人标签匹配度 (0.3-1.5)
Frisk店铺健康度惩罚 (healthScore < 3.0 时 = 0.3, 否则 = 0)
达人带货订单量公式：

OrderQty = BaseOrder × ConversionRate × (1 + (Vplayer - Vexpected) × 2)

其中 ConversionRate = 达人近期带货表现 × 区域客单价匹配系数

3.5 物流履约系统 (LogisticsSystem)

📬 自发货模式

  • 订单状态为 pending 时出现在"打包台"
  • 玩家点击"打包发货" → 扣减库存 → 计算运费 → 状态变为 shipped
  • 时效要求：订单生成后48小时(游戏时间)内必须发货
  • 超时惩罚：扣0.2健康分 + $50/单罚款

🏭 海外仓模式

  • 需提前采购并囤货至海外仓（批量发货到仓，N天后入库）
  • 订单生成后 自动秒发（状态立即变为 shipped）
  • 仓储费：每件每天 $0.05-$0.15（按区域）
  • 滞销风险：库存超过30天未售出，仓储费翻倍
// 运费计算
export const LogisticsSystem = {
  calculateShippingCost(
    product: { volume: number; weight: number },
    quantity: number,
    region: RegionId,
    shippingType: ShippingType
  ): number {
    const totalWeight = product.weight * quantity;
    const totalVolume = product.volume * quantity;

    if (shippingType === 'overseas') {
      // 海外仓本地配送：便宜
      return Math.max(3.99, totalWeight * 0.5);
    }

    // 自发货跨境：按重量和体积取大值
    const byWeight = totalWeight * REGION_SHIPPING_RATES[region].perKg;
    const byVolume = totalVolume * REGION_SHIPPING_RATES[region].perCubic;
    return Math.round(Math.max(byWeight, byVolume, 5.99) * 100) / 100;
  },
};

3.6 财务结算系统 (FinanceSystem)

💰 每日结算公式

每日收入 = Σ(已签收订单总额) - 平台佣金 - 达人佣金 - 退款
每日支出 = 采购成本 + 物流运费 + 海外仓仓储费 + 固定运营成本($20/天)
净利润 = 每日收入 - 每日支出

平台佣金 = 订单总额 × 区域平台费率 (SEA:5%, UK:8%, US:12%)
达人佣金 = 达人带货订单总额 × 约定佣金比例
固定运营成本 = $10/天 + $2×店铺等级

3.7 随机事件引擎 (EventEngine)

🎲 事件触发流程

  1. 每日结算时，遍历所有事件
  2. 检查触发条件：区域匹配 + 天数范围 + 店铺状态 + 概率roll
  3. 条件满足 → 暂停游戏时间 → 弹出事件对话框
  4. 玩家选择 → 概率判定成功/失败 → 施加效果
  5. 事件进入冷却
📋 计划事件库（≥15个）： 具体事件内容参见 GDD 第4章。包括：假货小黑屋、货不对板差评、超级爆单危机、平台政策突变、物流商涨价、达人跳单、竞品恶意差评、汇率波动、海关扣货、网红自发带货（正面）等。

3.8 区域解锁系统 (RegionSystem)

区域解锁条件特色
🇮🇩 东南亚 (SEA)初始解锁低客单价、快回款、COD风险
🇬🇧 英国 (UK)店铺Lv.3 + 累计营收$5,000中客单价、高退货率、VAT合规
🇺🇸 北美 (US)店铺Lv.6 + 累计营收$20,000高客单价、必须海外仓、严侵权

3.9 存档系统 (SaveSystem)

💾 存档机制

  • 自动存档：每日结算后自动保存到 IndexedDB
  • 手动存档：3个存档槽位
  • 存储内容：整个 GameState 序列化为 JSON
  • 存储键：tokshop-save-slot-{n}
  • 兼容性：存档包含版本号，加载时校验+迁移
