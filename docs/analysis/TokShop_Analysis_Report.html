1.2 架构评估

✅ 架构优点：
  • 三层分离干净：逻辑层（src/game/）纯函数无副作用，状态层（src/stores/）做中间桥接，渲染层（src/components/）只订阅状态。架构设计是此项目最大的亮点。
  • 类型系统完整：所有核心实体类型定义清晰，Union类型使用得当（RegionId, OrderStatus, RiskLevel等），初始状态常量化。
  • 系统模块化好：每个System是一个独立模块，通过统一接口暴露，依赖方向清晰。
  • 公式集中管理：formulas.ts 汇总所有计算公式，便于调整平衡性。
⚠️ 架构缺陷：
  • 单个巨型Store：gameStore.ts 超过600行，所有状态和action集中在一个Zustand store中。文档规划了多Store（playerStore, inventoryStore等）但未实施。
  • advanceOneDay 是内部函数：每日结算逻辑写在 store 文件底部而非独立系统，不便测试和复用。
  • 缺少中间件：无日志、无持久化中间件、无DevTools集成。
  • 3D与游戏逻辑脱节：场景组件几乎不读取游戏状态（只有包裹数量），未实现文档规划的"点击场景物体→弹出面板"交互。

2 核心问题诊断

2.1 问题一：没有故事

游戏完全没有叙事系统。以下逐一列举：

🔴 缺失的叙事维度

缺失项当前状态影响
玩家身份/角色 玩家只是一个抽象的"店主"，没有名字、背景、人设 无代入感，玩家不知道自己"是谁"
剧情推进 只有天数累加，没有任何阶段性剧情节点 无目标感，"为什么要继续玩"的问题无法回答
事件叙事链 14个事件随机触发，互相孤立，触发过就不再出现 事件是"偶发噪音"而非"剧情线索"
达人关系/对话 15个达人只有属性面板+emoji头像，bio字段仅展示用 达人只是"工具人"，不是"角色"
对话系统 文档规划的 dialogue.ts 从未创建 所有交互都是数值变动，没有人际交流
胜利条件 只有失败条件（资金≤-$500触发GameOver），无通关目标 游戏只有"不要输"，没有"我要赢"
难度曲线 Day1和Day100玩法完全相同 无新系统解锁、无新挑战，后期枯燥

2.2 问题二：流程不完善

核心循环虽可跑通，但每个环节都停留在"最简可行"层面，缺乏运营深度和策略空间。

🟡 流程缺陷一览

环节当前做了什么缺少什么
选品 从固定商品池按区域采购，批量折扣 商品趋势周期、季节性、新品上线、供应商关系、议价
上架 编辑标题→黑名单检测→通过/不通过 认证办理、法务投入、灰度合规（擦边策略）、A/B标题测试
达人 选达人→调佣金→roll概率→成功出单/失败冷却 关系养成、多次合作、独家签约、对话交涉、达人数据分析
物流 点"发货"→扣库存+运费→状态变更 多物流商选择、保险、包裹追踪、旺季爆仓、运费谈判
财务 每日自动结算→看报表 贷款工具、现金流预测、账期管理、汇率操作、税务规划
店铺 看等级→看升级条件→（点了升级没反应） 升级功能本身有BUG，更不用说升级后的新能力解锁
区域 满足条件→解锁→即时切换 切换过渡成本、区域特有玩法（VAT申报、知识产权诉讼）、跨区域策略
竞争 无 同行AI、价格战、抢达人、市场份额

3 逐系统详细分析

3.1 时间系统 (GameLoop) 评级 B+

✅ 做得好的

  • 基于 RAF 的独立时间循环，与渲染帧解耦
  • 4档速度 + deltaClamp防标签页切换时间跳跃
  • tick 返回"本帧过了几天"的设计允许多日批量处理
  • getDayProgress() 驱动 TopBar 进度条

⚠️ 可改进

  • 缺少"暂停时仍然可以操作面板"的约束（事件触发时设 gamePhase='event' 来暂停，但这与 gameSpeed='pause' 是两个机制）
  • 30秒/天的1x速度偏快，建议增加 "0.5x" 档（60秒/天）给新手

3.2 选品系统 (SourcingSystem) 评级 C

当前实现

  • 商品池来自 products.ts 的20个固定商品
  • getAvailableProducts() 用 seeded shuffle + 每7天轮换，显示8-12个
  • 采购操作：选数量→选仓库→扣款→生成在途库存
  • 批量折扣：≥100件9折，≥500件8折

❌ 缺失

  • 商品生命周期：无"新品上线 / 爆款期 / 衰退期"的时间变化。永远同一个货盘，只是每7天打乱顺序
  • 趋势/热度：无季节性（圣诞礼品、夏季防晒）、无潮流变化
  • 供应商差异：所有商品来自同一个"供应商"，无供应商评级、关系、议价
  • 在途库存可视化不足：arrivalDay 存在但在UI中仅显示一个预计到货日期，无法看到"在途货品清单"

💡 改进方向

  • 给商品加 "热度" 属性（上升期/巅峰/衰退），影响自然流量和达人匹配
  • 每N天随机"上新"N个新品、下架旧品；季节因素影响某些品类价格/需求
  • 2-3个供应商可选：便宜但不稳定 / 贵但品质好 / 中等但品类全

3.3 上架/合规系统 (ListingSystem) 评级 C+

当前实现

  • 三个黑名单词库：品牌词(30+) + 绝对化用语(20+) + 医疗功效词(20+)
  • 三级处罚：轻(警告) / 中($200+扣0.3分) / 重($500+扣1.0分)
  • 山寨品+品牌词 = 自动重罚

❌ 缺失

  • 合规策略层：只能被动检测，无法主动投入（如办认证、请法务降低检测概率）
  • 无灰度地带：实际跨境电商中很多卖家擦边经营（"媲美XX品牌"、"XX同款"），但当前系统是硬性黑白
  • 检测太机械：纯字符串匹配，不考虑上下文。比如"不是Nike"也会触发品牌词违规
  • 风险等级(genuine/whiteLabel/counterfeit)只影响处罚：不影响自然流量质量、退货率、达人合作意愿等其他维度

💡 改进方向

  • 引入"合规投入"维度：花钱办认证（降低医疗词检测）、请法务顾问（自动过滤部分违规词）
  • 模糊匹配加上下文判断，减少误报
  • 商品风险等级影响更多系统：山寨品高退货率、白牌品达人意愿降低

3.4 达人系统 (AffiliateSystem) 评级 D+

当前实现

  • 13个达人，按区域+层级分布，各有标签、期望佣金、基础意愿等属性
  • 合作流程：选达人→选商品→调佣金slider→看预估→点击"发起合作"→roll概率→成功生成订单 / 失败进入7天冷却
  • 订单量计算公式考虑了佣金溢价、达人近期表现、区域客单价系数

❌ 缺失（此系统最需要深化）

  • 达人关系养成：无好感度/信任度。多次合作无积累效果，每次都是独立事件
  • 达人交互过程：无对话、无交涉、无讨价还价。只是点了按钮→看结果
  • 达人状态太简单：只有 available / coolingDown 两种。无"长期合作中"、"已签约专属"、"被竞品挖走"等状态
  • 佣金策略无深度：slider从5%到40%，但只有"提得越高成功率越高"一个维度。实际应该有：佣金太高→达人怀疑产品质量→反而降低意愿
  • 达人数据无复盘：合作过达人的历史数据（ROI、退货率、满意度）无从查看
  • 达人也会自然成长/过气：所有达人属性是静态的

💡 改进方向（重点）

  • 引入"达人关系值"（0-100），多次成功合作提升→解锁折扣佣金、达人主动推荐等
  • 合作邀约改为"发起邀约→达人回应（对话形式）→玩家可选择调整条件"的对话树模式
  • 达人状态扩展为：available / negotiating / contracted / exclusive / coolingDown / poached
  • 合作历史面板：ROI、退货率、合作次数、最近合作结果
  • 达人动态属性：粉丝数、performance会根据其近期表现波动

3.5 物流系统 (LogisticsSystem) 评级 B-

当前实现

  • 自发货：手动点"发货"→扣库存+运费→状态变shipped
  • 海外仓：提前囤货→订单生成后自动发货，仓储费$0.03-$0.15/件/天，超30天翻倍
  • 超时惩罚：pending订单超过deadline→$50+5%订单金额罚款+扣健康分
  • 运费按重量/体积取大值×区域费率

❌ 缺失

  • 物流商选择：只有一个默认物流方式。实际应有多家可选（便宜但慢/贵但快/不稳定但偶尔极快）
  • 包裹追踪：shipped到delivered之间只有inTransit一个状态，无追踪粒度
  • 旺季压力：无节假日爆仓风险、无运费波动
  • 物流保险：高价值订单无保险选项
  • 仓储费仅在系统计算：UI中没有库存积压风险提示

💡 改进方向

  • 2-3个物流商选择（如"兔子速递"便宜、"飞鹰物流"快），不同区域有不同物流商
  • 包裹追踪进度条/时间线
  • 库存周转率警告（>30天积压标红）

3.6 财务系统 (FinanceSystem) 评级 C

当前实现

  • dailySettle() 计算：已签收订单回款 - 退款 - 平台佣金 - 达人佣金 - 运费 - 仓储费 - 运营成本
  • generateOrganicOrders() 根据声誉+区域基础流量每日生成随机订单
  • FinancePanel 展示：现金、今日营收/支出/净利、累计数据、应收应付

❌ 缺失

  • 现金流管理工具：无贷款、无融资、无账期管理。资金紧张时唯一的选择是"赶紧发货回款"
  • 汇率操作：汇率利好事件存在，但汇率本身是静态的（没有日常波动）
  • 税务：无VAT、无所得税——区域间应该有税务差异
  • 财务预测：无法看到"未来N天预计回款/支出"
  • 采购成本不计入每日结算：采购成本在采购时直接扣减gold，但 finance 报表中 sourcingCost 始终为0

💡 改进方向

  • 短期贷款工具（高利贷/银行），不同利率和期限
  • 汇率波动系统（每天微小波动，事件时大幅波动）
  • 现金流预测面板

3.7 事件系统 (EventEngine) 评级 B

当前实现

  • 15个事件：5风险 + 5机遇 + 5中性
  • 触发条件：区域、天数范围、健康分、店铺等级、商品、pending订单数 + 概率roll
  • 解析流程：tryTriggerEvent→暂停游戏→EventDialog→玩家选A/B/C→resolveEventChoice掷骰→applyEffects
  • 冷却机制：triggeredEventIds 记录已触发事件，永不重复

❌ 缺失（叙事维度）

  • 事件之间完全独立："假货小黑屋"和"竞品恶意差评"没有任何联系。实际上它们可以是同一条"知识产权线"的不同阶段
  • 事件无后续：选了某个选项后，这个事件就永远结束了，没有连环事件
  • 事件无角色：所有事件是"系统通知"风格，没有具体的人物（如"某位律师联系你"、"某位达人发来消息"）
  • 冷却机制过于绝对：triggeredEventIds 只增不减。cooldownDays 定义了但不生效——因为事件触发过一次就进黑名单了

💡 改进方向（重点）

  • 将14个事件重组为3-4条"事件链"（剧情线）。例如：
    1. 知识产权线：第一次违规→警告→律师函→诉讼威胁→最终结局（和解/胜诉/破产）
    2. 商业竞争线：竞品出现→恶意差评→价格战→行业联盟→市场格局确定
    3. 达人关系线：达人跳单→谈判→长期合作→独家签约
    4. 企业成长线：小店→爆单→融资→扩张→上市
  • 修复冷却：改为cooldownDays后重新加入触发池，而非永久排除

3.8 区域系统 (RegionSystem) 评级 B

当前实现

  • SEA(初始) → UK(Lv3+$5k) → US(Lv6+$20k)
  • 区域差异：客单价范围、物流时效、回款周期、退货率、COD、合规难度、佣金率、仓储费

❌ 缺失

  • 切换无成本：即时切换，无过渡期、无适应成本
  • 区域特有事件少：只有假货小黑屋(US)、海关扣货(UK)、暴雨延误(SEA)等少数区域限定事件
  • 无跨区域策略：无法同时运营多个区域，每次只能在一个区域
  • 区域解锁后内容不变：解锁新区域只是打开了"另一个难度"，没有新玩法

💡 改进方向

  • 多区域并行运营（解锁UK后可以在SEA和UK同时接单）
  • 区域特有玩法模块（US的知识产权诉讼，UK的VAT申报）
  • 切换冷却期（如切换区域后3天内新区域订单量减半）

3.9 店铺升级 (ShopPanel) 评级 D

🐛 严重BUG：店铺升级按钮没有绑定任何handler！

ShopPanel.tsx 中的升级按钮： 
<Button
  size="sm"
  disabled={条件不满足}
>
  升级
</Button>
缺少 onClick 属性。点击按钮不会有任何反应。

同时在 gameStore.ts 中：
  • 没有 upgradeShop action
  • getLevelUpRequirement() 公式存在但从未被 store 调用
  • player.shopLevel 在整个游戏中始终保持初始值1，永远不变
影响：店铺升级是解锁 UK/US 区域的前置条件（需要Lv.3和Lv.6），由于升级无法执行，玩家永远无法解锁后续区域。这是阻塞性BUG。

3.10 3D场景与UI 评级 D

当前实现

  • Office.tsx：地板、后墙、一张桌子（带屏幕发光）+ 打包台（带动态包裹）+ 货架 + 白板，全部使用 BoxGeometry
  • 包裹堆叠数量绑定 pending订单数
  • 电脑和打包台可点击 → 打开对应面板

❌ 缺失

  • 场景与游戏数据脱节：除包裹数量外，场景不反映任何游戏状态（资金多少、店铺等级、库存多少等）
  • 只有一个场景：文档规划的"仓库"和"店铺外景"场景未实现
  • 无可交互物体互动：点击只是触发面板，无3D动画（如打包台上包裹消失的动画）

4 改进方案（按优先级排列）

P0 必须修复 — 阻塞可玩性

#1 修复店铺升级功能

严重程度：🔴 阻塞性BUG（导致区域解锁系统无法触发）

  • 在 gameStore.ts 中添加 upgradeShop action：检查升级条件→扣费→shopLevel+1→解锁新商品/功能
  • 在 ShopPanel.tsx 中给升级按钮绑定 onClick
  • 升级后给予实质性回报：解锁新商品品类、降低平台费率、提升自然流量、解锁新达人层级

#2 增加胜利条件 / 里程碑系统

严重程度：🔴 游戏无目标则无驱动力

  • 短期里程碑（每7天）："本周完成20单"、"本周营收$500"——完成奖金币/声誉
  • 中期目标："成为金牌卖家(健康分≥4.8且累计营收$50,000)"、"解锁全部三个区域"
  • 最终胜利："跨境帝国：店铺Lv.10 + 三区域运营 + 累计营收$200,000"——触发胜利动画
  • 里程碑系统同时承担"引导玩家理解游戏深度"的教学功能

#3 增加每日/每周任务系统

严重程度：🟡 没有短期目标，玩家不知道该做什么

  • 每日任务（3个随机小目标）："完成5笔发货"、"采购一批新货"、"与达人合作1次"——奖励小额金币
  • 每周任务（1个较大目标）："本周达人带货订单超100单"——奖励声誉+解锁奖励
  • 任务UI：在Dashboard右侧或独立任务面板展示
  • 连续完成有combo奖励

P1 叙事层 — 解决"没有故事"

#4 角色创建系统

游戏开始时让玩家选择身份背景，不同身份不同初始条件和剧情方向。

  • 🏢 辞职创业者：初始资金$5,000，店铺Lv.2起，但背负$3,000贷款（30天还$4,000）。剧情线：追求独立→融资→上市
  • 🏭 国内电商老手：初始资金$1,500，但有供应商关系（采购价常驻9折）。剧情线：老炮出海→适应新规则→建立跨境供应链
  • 🎓 大学生创业：初始资金$800，但达人合作意愿+20%（年轻懂社媒）。剧情线：小打小闹→抓住风口→一炮而红

#5 剧情事件链

将当前14个离散事件重组为3-4条剧情线，事件按阶段依次触发（而非完全随机）。

  • 📜 知识产权线（4阶段）：Stage1"第一次警告"→Stage2"律师函"（选A交罚款进入Stage3A和解，选B硬刚进入Stage3B诉讼）→Stage4"结局"
  • ⚔️ 商业竞争线（3阶段）：竞品出现→价格战/恶意差评→行业洗牌
  • 🤝 达人伙伴线（3阶段）：达人跳单→重新谈判→长期签约或决裂
  • 📈 企业成长线（3阶段）：爆单→资金链危机→扩张or破产
  • 技术实现：事件增加 chainId 和 chainStage 字段，同一chain的事件按stage顺序触发

#6 达人关系系统（含对话）

  • 好感度/信任度（0-100）：
    • 成功合作 +5~15（取决于佣金是否高于期望）
    • 佣金低于期望但成功 +3（达人觉得亏了）
    • 失败但不扣分
    • 退货率高 → 扣好感
  • 关系等级：陌生人(0-20) → 熟人(21-50) → 朋友(51-80) → 伙伴(81-100)
  • 关系等级奖励：朋友级→佣金9折；伙伴级→达人主动推荐新品+独家带货
  • 对话树：邀约时不是直接roll，而是进入简化对话（达人给出回应文本+玩家可选择调整条件）
  • 合作历史面板：每个达人单独展示合作次数、总出单量、总佣金支出、退货率

#7 邮件/消息系统

替代当前单调的通知栏。消息按来源分类，有发件人、有上下文。

  • 消息来源：平台通知、供应商消息、达人私信、客户投诉、律师函
  • UI形式：类邮件客户端的收件箱面板（替代当前通知Modal）
  • 部分消息可回复/可操作：供应商砍价→可接受/还价；达人私信→可回复开启合作

P2 玩法深化 — 解决"流程不完善"

#8 选品策略层：商品生命周期 + 趋势

  • 商品热度周期：每个商品有 trend 属性（rising / peak / declining / dead），影响自然流量和达人匹配意愿
  • 新品上线：每14天随机"上新"3-5个新品（随机品类、随机价格带）
  • 下架旧品：热度跌至dead的商品从货盘移除（已购库存不受影响，但不再有新订单）
  • 季节性：按游戏天数模拟季节（如Day1-30夏季→防晒/墨镜热销；Day60-90冬季→家居/宠物热销）

#9 合规策略层：认证 + 法务系统

  • 办理认证：花费金钱+等待时间获取FDA/CE认证。有认证后该品类商品可免医疗词检测
  • 聘请法务：月费制，自动过滤部分轻/中违规（如绝对化用语），重度违规仍需手动处理
  • 擦边策略：允许使用"XX同款"、"媲美XX"等灰色表述，但有概率被平台抽查→抽查到按中度违规处理

#10 营销系统：不只是达人带货

  • 投流广告：投入$100-$1000→获得曝光→生成额外订单（ROI不确定，受商品热度、素材质量影响）
  • SEO优化：每月固定投入→提升自然流量10-30%
  • 社媒运营：玩家可选择"自己运营账号"，投入时间（冷却天数）换取免费流量
  • 平台活动：不定期出现的限时活动（如"双11大促"），参与需满足条件

#11 员工系统

  • 店铺Lv.3后解锁"招聘"面板
  • 客服专员：降低退货率2-5%，月薪$200
  • 运营专员：提升自然流量20-50%，月薪$300
  • 打包员：自动处理发货（不再需要手动点），月薪$150
  • 人力成本成为新的运营维度

#12 竞争对手AI

  • 同区域存在2-3个AI店铺，有名称、主营品类、价格策略
  • 竞争行为：价格战（竞品降价→你的订单量受影响）、抢达人（高价值达人可能被竞品签约）、恶意差评
  • 市场报告：每7天一次"市场周报"，展示你的市场份额和各竞品动态

#13 物流策略深化

  • 多物流商选择：兔子速递(便宜2天慢)、飞鹰物流(贵1天快)、鲸鱼海运(最便宜但7天慢，仅UK/US)
  • 物流保险：订单金额的3%购买保险，物流途中丢失/损坏全额赔付
  • 旺季爆仓：节假日期间特定物流商暂停或大幅涨价

#14 现金流管理工具

  • 短期贷款："极速贷"（高利贷，30天还本息130%）、"银行经营贷"（店铺Lv.5解锁，利率低但需审核）
  • 账期管理：可与供应商协商延长付款周期（以降低采购折扣为代价）
  • 现金流预测面板：未来7天的预计回款、预计支出、余额变化曲线

#15 评价与复购系统

  • 每个已签收订单有概率产生评价（好评/中评/差评），受产品质量(riskLevel)和物流时效影响
  • 好评积累→提升自然转化率
  • 差评积累→降低自然流量→需要"差评处理"操作（退款/补偿/申诉）
  • 复购率：老客户有概率再次下单（受满意度影响）

P3 体验优化

#16 新手引导系统
